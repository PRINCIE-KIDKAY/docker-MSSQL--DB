# docker-MSSQL--DB

This project provides a simple `docker-compose` setup for running a Microsoft SQL database with Adminer (a lightweight database management tool).

## 📦 Requirements

- [Docker](https://www.docker.com/get-started)
- [Docker Compose](https://docs.docker.com/compose/install/)

## 🚀 Getting Started

### 1. Clone this repository (or copy the `docker-compose.yml` to your project)

# bash
- git clone https://github.com/PRINCIE-KIDKAY/docker-MSSQL--DB.git
- cd your-project-directory


## Start the containers
`docker-compose up -d`


# Stop the containers

`docker-compose down`
